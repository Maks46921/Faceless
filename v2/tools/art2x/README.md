# Графика мира в двойной плотности (HD 2×) для 2.x

Damir, 2026-10-30: люди стали детальнее (faceless/ideas/people_hd/), под них перерисован мир: у каждого тайла и предмета вдвое больше пикселей по каждой оси. Размеры в мире не меняются.

## Что внутри

- `assets/` можно положить вместо `v2/assets/tiles.png`, `tiles.txt`, `props/`, `props.txt` (также в `Faceless_hd2x_assets.zip`).
  - `tiles.png` 512×256: те же 122 тайла с теми же координатами в `tiles.txt`, но тайл 32×32 вместо 16×16.
  - `props/*.png`: те же 161 предмет, каждый кадр вдвое больше. **`props.txt` хранит мировые размеры (как раньше)**, текстура = 2× от них. У 9 вывесок и граффити размер сменился на 1–3 px, поэтому берите новый `props.txt`.
- `people/`: два детальных NPC (кадр 96×96, стойка + 8 кадров шага, цветные, без палитрового шейдера) и их генератор.
- `tools/`: генераторы. Запуск из `tools/`: `python3 gen_tiles.py <assets> && python3 gen_props.py <assets> && python3 post2x.py <assets>`.
  - `k2.py`: старые генераторы рисуют в 2× без изменений своего кода координат. Тонкие линии и обводки становятся вдвое тоньше, кривые и текст глаже.
  - `detail_tiles.py`: тайлы перерисованы вручную. Это фасады всех 6 типов (стена, окно 2×2, карниз с сухариками, пояс, рустованный цоколь), стены в разрезе, земля, камень, тротуар, газон, асфальт, гравий, 5 перекрытий. Список в `tiles_detailed.txt`.
  - `detail_props.py`: предметы перерисованы вручную. Это фонарь, таксофон, киоск, остановка, скамейка, контейнер, тополь, берёза, 5 «Жигулей», милиция, скорая, 3 двери подъезда. Список в `props_detailed.txt`.
  - `post2x.py`: проход объёма для остальных предметов и тайлов (свет сверху слева, тени под выступами, зерно). Ручные работы он пропускает. **Запускать один раз на свежую генерацию**, повторный запуск затеняет дважды.
- `previews/`: сравнение старого и нового (улица, фасады, предметы).

## Как подключить в игре (src/res.gd, src/view.gd)

1. **Разрешение картинки.** Сейчас мир рендерится в SubViewport размером K.VIEW_W×K.VIEW_H и растягивается на экран. Чтобы мелкие пиксели было видно, все 5 SubViewport надо сделать вдвое больше и поставить камере zoom ×2 (или canvas_transform scale 2). Мировые координаты остаются прежними. Иначе 2× текстуры просто ужмутся обратно. В compose.gdshader обновить `tex_size`.
2. **Тайлы.** В `_load_tiles`: `src.texture_region_size = Vector2i(32, 32)`, `tileset.tile_size = Vector2i(32, 32)`, точки коллизий ×2 (h = 16, верхняя полоса 8), а каждому TileMapLayer поставить `scale = Vector2(0.5, 0.5)`. Сетка и физика в мире останутся 16 px. Проверить места, где используются `map_to_local`/`local_to_map` без учёта scale слоя.
3. **Предметы.** В `prop_sprite`: `s.scale = Vector2(0.5, 0.5)`, `s.offset = Vector2(-w, -2 * h)` (offset в пикселях текстуры, w/h из props.txt). `hframes` прежние. Там, где на спрайт предмета ставится свой `scale` (например, разворот), умножать на 0.5.
4. **Люди.** Слои фигур `assets/fig` пока 48×48. В 2× вьюпорте они будут нарисованы крупным пикселем рядом с мелким миром. Следующий шаг: перевести gen_chars.py на кадр 96 в стиле `people/` (части-маски по скелету, свет, выборочная обводка) с сохранением материальной кодировки для figure.gdshader. После этого фигурам тоже ставить scale 0.5.
5. Фильтр текстур остаётся nearest.
